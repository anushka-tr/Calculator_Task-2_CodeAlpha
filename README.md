# 🧮 Calculator - CodeAlpha Task 2

A simple and responsive Calculator built using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

## 📌 Project Overview

This project is a basic web-based calculator designed to perform standard arithmetic operations through an intuitive and user-friendly interface. It provides quick and accurate calculations while maintaining a clean design.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🗑️ Clear/Delete functionality
- ⌫ Backspace support
- 🖥️ Responsive user interface
- ⚡ Instant calculation results
- 🎨 Clean and modern design

## 🛠️ Technologies Used

- **HTML5** – Structure of the calculator
- **CSS3** – Styling and responsive layout
- **JavaScript** – Calculator logic and functionality

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/anushka-tr/Calculator_Task-2_CodeAlpha.git
```

2. Open the project folder.

3. Double-click the `index.html` file or open it in any web browser.
